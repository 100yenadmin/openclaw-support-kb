# Mxc plugin

OS-level sandboxed tool execution via MXC for MXC-capable Windows hosts: runs commands in ProcessContainer (Windows) with configured MXC policy files.

## Distribution

- Package: `@openclaw/mxc-sandbox`
- Install route: npm; ClawHub
